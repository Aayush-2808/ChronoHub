# ChronoHub - LifeSync

Simple TYCS mini-project using HTML, CSS, JavaScript, Python, Flask and SQLite.

## Run
1. Install Python 3.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run `pip install -r requirements.txt`
5. Run `python app.py`
6. Open `http://127.0.0.1:5000`
